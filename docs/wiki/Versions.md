# Versions

Every wiki page starts with an **Applies to** line: the portnook version (major.minor) the page was last checked
against. When a release changes the UI or a feature that a page describes, the page is updated and its line moves
to that version. Pages whose topic did not change keep their older line; they are still valid for newer
versions.

## Editions

| Edition | portnook | Notes |
|---|---|---|
| **rc1** | 0.27.x–0.30.x | First release candidate before going public. All pages written; 0.30 adds the PROXY protocol. |

## Older versions

The wiki shows the current edition only. The pages for any release are kept in the repository under
`docs/wiki/` at that release's tag:

```
https://github.com/ghostgw-nook/portnook/tree/v<version>/docs/wiki
```

Example: [v0.27.0](https://github.com/ghostgw-nook/portnook/tree/v0.27.0/docs/wiki).
